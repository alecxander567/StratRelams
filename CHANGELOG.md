# Changelog

All notable changes to StratRealms will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0-beta] — 2026-09-23

### Added

- Initial public beta release
- 8 playable races with unique Marshal skills
- Single-player battles against AI
- Local Wi-Fi multiplayer
- 15 premade strategies + custom formations
- Collections, shop, gold economy
- Achievements with reward tiers
- Mid-match save & load
- Interactive tutorial

### Notes

- This is a beta — expect balance changes, skill adjustments, and UI polish in future updates
